Analytical Intelligence

Real-time Security Intelligence and Event Management Platform. Powered by Machine Learning and Signature-based Detection.

About The Project

Analytical Intelligence is a comprehensive security monitoring solution that combines machine learning-based anomaly detection with signature-based intrusion detection. It provides real-time visibility into security events across your infrastructure, enabling rapid threat detection and response.

Technologies

Suricata IDS

High-performance network IDS/IPS with custom rule support for signature-based threat detection.

TensorFlow ML

LSTM neural networks for SSH anomaly detection and behavioral analysis.

NFStream

High-performance network flow collection and feature extraction library.

PostgreSQL

Robust relational database for storing events, detections, and analytics data.

SQLAlchemy

Python ORM for database migrations, async queries, and model management.

FastAPI Backend

High-performance async Python backend with real-time event processing.

Jinja2 Templates

Powerful templating engine for dynamic HTML rendering and UI components.

Docker

Containerized deployment for consistent and scalable infrastructure.

MobaXterm
